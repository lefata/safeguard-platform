# Safeguard Platform - Installation Guide

## Prerequisites

- Node.js 20+
- PostgreSQL 16+
- npm or yarn
- Vercel account (for deployment)
- SMTP server (for email notifications)
- Google Cloud Console project (for Google SSO)
- Azure AD tenant (for Microsoft SSO)
